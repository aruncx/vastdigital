# Vidya Digital Connect 2026

Interactive digital-campus launchpad for the First-Year B.Tech Student Induction Programme at Vidya Academy of Science and Technology.

## GitHub Pages

1. Upload `index.html`, the `assets` folder, and `favicon.svg` to the repository.
2. Keep the folder structure unchanged.
3. In GitHub: **Settings → Pages → Deploy from a branch → main → / (root)**.
4. Open the generated GitHub Pages URL.

The hero campus image is loaded from `assets/vidya-campus-hero.jpg`, so it is served by GitHub Pages rather than embedded inside the HTML.
